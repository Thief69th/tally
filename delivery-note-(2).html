Delivery Note Settings & Options in TallyPrime

Delivery Note सही तरीके से उपयोग करने के लिए TallyPrime में कुछ Important Features और Settings Enable करनी पड़ती हैं। नीचे सभी Settings Step by Step दी गई हैं।

अध्याय 1: Inventory Features Enable करना

स्टेप 1 F11 Features खोलें

  • Gateway of Tally पर जाएं।
  • कीबोर्ड से F11 दबाएं।
  • अब Inventory Features चुनें।

स्टेप 2 Important Inventory Options Enable करें

Maintain Inventory = Yes
Integrate Accounts and Inventory = Yes
Use Tracking Numbers = Yes
Use Order Processing = Yes
Use Multiple Godowns = Yes
  • Maintain Inventory : Stock Maintain करने के लिए।
  • Use Tracking Numbers : Delivery Note और Sales Invoice को Link करने के लिए।
  • Use Order Processing : Sales Order और Purchase Order Enable करने के लिए।
  • Use Multiple Godowns : अलग-अलग Stock Locations Manage करने के लिए।

अध्याय 2: Voucher Type Settings Enable करना

स्टेप 1 Voucher Type Open करें

  • Gateway of Tally > Alter > Voucher Types में जाएं।
  • अब Delivery Note चुनें।

स्टेप 2 Delivery Note Settings Enable करें

Type of Voucher = Delivery Note
Method of Voucher Numbering = Automatic
Use Effective Dates = Yes
Make Optional as Default = No
Use Common Narration = Yes
  • Voucher Number Automatic रखने से नंबर खुद Generate होगा।
  • Effective Dates से Delivery की अलग Date रख सकते हैं।
  • Narration Enable करने से Dispatch Details लिख सकते हैं।

अध्याय 3: Godown Enable करना

स्टेप 1 Godown Feature Activate करें

  • F11 Inventory Features में जाएं।
  • Use Multiple Godowns = Yes करें।

स्टेप 2 Godown Create करें

  • Create > Godowns में जाएं।
  • Example:
Main Godown
Delhi Stock
Warehouse 1

अध्याय 4: Stock Item Create करना

स्टेप 1 Stock Group Create करें

  • Create > Stock Group में जाएं।
  • Example: Electronics, Mobile, Laptop

स्टेप 2 Unit Create करें

  • Create > Units में जाएं।
  • Example: Nos, PCS, KG

स्टेप 3 Stock Item Create करें

Name : Dell Laptop
Under : Laptop
Units : Nos
Opening Balance : 20 Nos

अध्याय 5: Tracking Number Enable करना

  • Delivery Note बनाते समय Tracking Number दिखाई देगा।
  • यह Number बाद में Sales Voucher में उपयोग होता है।
  • इससे Pending Delivery Track की जा सकती है।
Tracking No : TN-001

अध्याय 6: Delivery Note Entry के लिए Required Masters

Master Purpose
Ledger Customer Account बनाने के लिए
Stock Group Items Category बनाने के लिए
Stock Item Products बनाने के लिए
Units Quantity Measure करने के लिए
Godown Stock Location Manage करने के लिए
Important Note:

यदि Tracking Numbers या Inventory Features Enable नहीं होंगे, तो Delivery Note सही तरीके से काम नहीं करेगा।
Shortcut Revision:

F11 = Features
Alt + F8 = Delivery Note
Ctrl + A = Save Voucher
F8 = Sales Voucher
Alt + C = Create Master
