How To Create Company In Tally Prime Hindi

Tally Prime में Company Create कैसे करें?

Step-by-Step Guide with Important Shortcut Keys

Introduction

अगर आप पहली बार Tally Prime इस्तेमाल कर रहे हैं तो सबसे पहला काम होता है नई कंपनी बनाना। बिना Company Create किए आप Accounting, GST, Billing और Inventory का काम शुरू नहीं कर सकते।

इस पोस्ट में हम सीखेंगे कि Tally Prime में Company Create कैसे करते हैं, सभी जरूरी Details कैसे भरते हैं और Important Shortcut Keys का उपयोग कैसे होता है।

Tally Prime में Company Create कैसे करें?

Step 1: Tally Prime Open करें
Step 2: Home Screen में जाएं
Step 3: Create Company Option Select करें
Step 4: Company Details भरें
Step 5: आखिर में Ctrl + A दबाकर Save करें

Company Create करते समय कौन-कौन सी Details भरनी होती हैं?

Field Details
Company Name अपनी कंपनी का नाम
Mailing Name Company Name जैसा ही
Address पूरा Address
State अपना State Select करें
Country India
Pincode Area Pincode
Phone Number Mobile Number
Email Email Address
Financial Year Begins 1 April से शुरू होता है
Books Beginning From काम शुरू होने की Date
Security Control जरूरत हो तो Yes करें
Base Currency Symbol ₹
सभी Details भरने के बाद Ctrl + A दबाने पर Company Save हो जाती है।

Company Save होने के बाद क्या आता है?

जब Company Successfully Save हो जाती है तब Tally Prime का मुख्य Gateway Screen खुल जाता है।

इसके बाद कई Important Options दिखाई देते हैं:

  • Masters
  • Transactions
  • Reports
  • Banking
  • Utilities
  • Import Data
  • Chart of Accounts

यहीं से आगे का पूरा Accounting काम शुरू होता है।

Gateway of Tally में क्या-क्या काम होता है?

Option काम
Masters Ledger, Group, Stock Item Create करना
Transactions Sales, Purchase, Payment Entry करना
Reports Balance Sheet, Profit & Loss देखना
Banking Bank Related काम
Utilities Import, Export और अन्य Tools
Chart of Accounts सभी Ledgers और Groups देखना

Tally Prime Shortcut Keys List

Shortcut Key काम
Alt + K Company Menu Open करता है
Alt + F3 Company Info Open करता है
Ctrl + A Save करने के लिए
F11 Company Features Open करता है
F12 Configuration Settings खोलता है
Alt + F1 Detailed View दिखाता है
Alt + F2 Date Change करने के लिए
Alt + G Go To Menu Open करता है
Alt + Z Zoom Feature
Ctrl + Q Current Screen Quit
Ctrl + N Calculator Panel Open

Alt + F3 में कौन-कौन से Options होते हैं?

  • Create Company
  • Select Company
  • Shut Company
  • Alter Company
  • Backup
  • Restore
  • Split Company Data
  • Quit

Important Tips

  • State सही चुनें ताकि GST सही काम करे
  • Regular Backup लेते रहें
  • Shortcut Keys सीखने से काम तेज होता है
  • Ctrl + A सबसे ज्यादा उपयोग होने वाली Key है
  • पहले Ledger और Voucher Entry सीखना शुरू करें

Conclusion

अब आप आसानी से Tally Prime में नई Company Create कर सकते हैं। इसके साथ आपने Gateway of Tally, Shortcut Keys और Alt + F3 Menu के बारे में भी समझ लिया।

अगर आप Beginner हैं तो आगे Ledger Create करना, GST Setup और Voucher Entry सीखना अगला Step होना चाहिए।
