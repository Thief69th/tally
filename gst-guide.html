GST के प्रकार

भारत में GST के 4 प्रकार और Tally में उनका उपयोग

चार प्रकार के GST
CGST
Central Goods & Services Tax
Same state में transaction होने पर Central Government को जाता है।
SGST
State Goods & Services Tax
Same state में transaction होने पर State Government को जाता है।
IGST
Integrated Goods & Services Tax
Different state या Import/Export में लगता है। Central Govt को जाता है।
UTGST
Union Territory GST
Delhi, Chandigarh जैसे UT areas में SGST की जगह यह लगता है।
Simple Rule

कब कौन सा GST लगेगा?

Same State
→
CGST + SGST दोनों लगेंगे
Example: UP से UP को बेचा → CGST 9% + SGST 9% = 18% Total
Diff. State
→
सिर्फ IGST लगेगा
Example: UP से Maharashtra को बेचा → IGST 18%
UT Area
→
CGST + UTGST लगेगा (SGST की जगह)
Example: Delhi, Ladakh, Chandigarh आदि

Tally Auto Calculate — 3 Steps
1

Stock Item में GST Rate Set करो

Gateway → Inventory Info → Stock Items → Create → GST Details में HSN Code और Tax Rate डालो।

2

Party Ledger में State Select करो

Accounts Info → Ledgers → Party का ledger खोलो → State field में सही state भरो।

3

Voucher बनाते वक्त Tally खुद Detect करेगा

Same state है → CGST + SGST automatically आएगा। Different state है → IGST automatically लगेगा।
